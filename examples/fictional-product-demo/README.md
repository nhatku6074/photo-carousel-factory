# Fictional focus-bottle demo

This example demonstrates the default five-slide structure with a fictional, unbranded reusable water bottle. It contains no real customer assets, trademarks, health claims, or provider credentials.

Render:

```bash
python ../../scripts/render_carousel.py .
```

Validate:

```bash
python ../../scripts/validate_carousel.py .
```

Upload the five files in `slides` in filename order. The contact sheet and machine-readable reports are written to `qa`.
